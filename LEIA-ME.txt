IRONFOX
Aplicativo web (PWA) para registrar treinos de academia.
Versão atual: 5.7.2
Atualizado em: 18/11/2026

O QUE É
O IronFox é um app web instalável (PWA) pensado para o celular.
Tema escuro, visual minimalista e funcionamento offline.
Funciona offline e sem conta: os dados ficam salvos no próprio
aparelho, no armazenamento local do navegador (localStorage). Se você
quiser, pode entrar com uma conta Google para sincronizar os treinos
entre aparelhos (Firebase Authentication + Firestore).

O QUE JÁ EXISTE
- Tela Início com calendário mensal minimalista.
- Navegação entre meses com as setas ‹ › ao lado do título; o botão
  "Hoje" volta ao mês atual. O próximo mês fica desabilitado quando
  você já está no mês atual.
- Lista com uma linha por dia do mês exibido, em ordem de data.
- Regra de status:
  - Dias passados sem treino registrado aparecem como "Descanso".
  - Hoje e dias futuros aparecem como "Pendente".
  - Quando houver treino salvo, a linha mostra os grupos musculares
    e o peso (ex.: "01/01/2026 - Perna + Abdômen - 68 kg"), com o
    nome do treino na cor do grupo (ou no degradê dos grupos). No
    calendário, o dia recebe uma estrela de dez pontas com essas
    mesmas cores.
- O app começa vazio, sem dados de exemplo.
- Tocar num dia do calendário ou numa linha do registro abre a tela
  do dia, onde se escolhem os grupos musculares treinados.

EVOLUÇÃO E RESUMO
- Abaixo do registro do mês, na parte de baixo da tela Início,
  aparecem primeiro o gráfico "Evolução" e depois o "Resumo do mês".
- Evolução: gráfico de linha simples. A aba "Peso corporal" mostra o
  peso do dia; a aba "Exercício" tem um seletor para escolher o
  exercício e mostra a maior carga feita em cada dia. Usa até os
  últimos 12 registros até o fim do mês exibido.
- Resumo do mês: quantidade de treinos, quantidade de faltas e a
  melhor sequência de dias treinados consecutivos no mês.

TELA DO DIA
- Aberta em "#/dia/AAAA-MM-DD" (ex.: "#/dia/2026-11-15").
- Lista os grupos musculares e, no fim, as opções "Descanso" e
  "Pendente".
- É possível marcar mais de um grupo no mesmo dia (seleção múltipla,
  marcada com "✓"). O botão "Salvar" grava o treino.
- "Descanso" e "Pendente" são exclusivos: ao escolher um deles os
  grupos marcados são limpos, e ao marcar um grupo o status é limpo.
- Depois de salvar (e ao abrir um dia que já tem treino), a tela
  mostra apenas as anotações: grupos, exercícios (séries e peso por
  série) e o peso do dia.
- No fim das anotações há um botão com lápis ("✎ Editar") para voltar
  ao formulário e alterar qualquer coisa.
- "Cancelar" no modo de edição volta às anotações sem salvar.
- Salvar sem nada marcado remove o registro daquele dia.
- Num dia sem registro, a tela abre direto no modo de edição;
  "Voltar" retorna para a Início.
- No modo de edição, "↻ Repetir último treino" copia os grupos e os
  exercícios (séries e pesos) do treino mais recente anterior ao dia.
  O peso corporal não é copiado.

ANOTAÇÃO DOS EXERCÍCIOS
- Ao marcar um ou mais grupos, aparece um bloco para cada grupo
  escolhido (separados por grupo), com uma linha por exercício.
- Cada exercício tem o nome e uma lista de séries. Em cada série você
  anota as repetições e o peso daquela série (kg, ex.: 7.5, 20.5):
  "1 = 10 - 5 kg", "2 = 21 - 8 kg"...
- "+ Série" adiciona outra série no mesmo exercício (já copia o peso
  da série anterior; as repetições ficam em branco). O "×" ao lado
  remove aquela série.
- Use "Adicionar exercício" quantas vezes precisar e o "×" do
  exercício para remover a linha inteira.
- No fim da tela há "Peso do dia" para anotar seu peso corporal
  (aceita duas casas decimais, ex.: 60.59). Esse valor aparece na
  linha do dia na tela Início.
- Os blocos aparecem na ordem dos grupos em src/config.js, então dois
  grupos escolhidos ficam separados na hora de anotar.

COMO ABRIR NO CELULAR
1. O app precisa ser servido por HTTP local ou HTTPS.
2. Com o servidor ligado, abra no Chrome:
   http://127.0.0.1:8080/
3. Para servir manualmente:
   cd /sdcard/Download/IronFox-main
   python3 -m http.server 8080
4. Se o Chrome mostrar uma versão antiga, recarregue ou abra com uma
   porta/consulta diferente (ex.: http://127.0.0.1:8081/) para
   escapar do cache do service worker.

INSTALAR NA TELA INICIAL
- Chrome: menu (tres pontos) > "Adicionar à tela inicial" / "Instalar".
- Depois de instalado, abre em tela cheia e funciona offline.
- O service worker guarda os arquivos do app no aparelho.

CONTA E SINCRONIZAÇÃO (OPCIONAL)
- A tela "Conta" abre pelo ícone de pessoa no canto superior direito
  da tela Início (discreto, para não atrapalhar o visual) e permite
  entrar e sair com uma conta Google. Logado, o ícone ganha um
  pequeno ponto de destaque.
- Sem entrar, nada muda: os treinos ficam somente no aparelho.
- Ao entrar, o app junta os treinos do aparelho com os da conta e
  passa a manter os dois iguais, em qualquer aparelho com a mesma
  conta.
- Cada dia guarda um "updatedAt" (carimbo de tempo). Ao sincronizar,
  vence a versão mais nova daquele dia.
- Um dia apagado é guardado como lápide ({ deleted: true }) para que
  a remoção também chegue aos outros aparelhos.
- A sincronização acontece sozinha: ao salvar um treino (pouco depois)
  e quando o app recebe mudanças de outro aparelho.
- O login usa pop-up do Google; se o navegador bloquear, o app tenta
  redirecionar. O endereço usado precisa estar em
  Authentication > Settings > Authorized domains (localhost e o
  domínio do Firebase Hosting já vêm autorizados; 127.0.0.1 precisa
  ser adicionado).
- Sem internet, o login não carrega, mas o app continua funcionando
  com os dados locais.
- O SDK do Firebase é baixado do CDN oficial
  (www.gstatic.com/firebasejs/10.14.1) só quando necessário; não há
  etapa de build nem "npm install".

COMO ATIVAR A CONTA NO CONSOLE DO FIREBASE
1. Build > Authentication > Começar > Sign-in method > Google: ative
   e salve.
2. Build > Firestore Database: crie o banco (Modo de produção,
   localização southamerica-east1).
3. Firestore > Regras: cole o conteúdo de firestore.rules e publique.
   As regras deixam cada pessoa ler e gravar apenas o próprio
   documento em users/{uid}.
4. Authentication > Settings > Authorized domains: inclua o endereço
   onde o app roda, se não for localhost.

PUBLICAR NO FIREBASE HOSTING (OPCIONAL, PARA HTTPS)
1. Instale o Node.js e rode uma vez: npm install -g firebase-tools
2. Na pasta do app: firebase login
3. Ainda na pasta: firebase deploy
   (o .firebaserc já aponta para o projeto iroxfox-f3b91 e o
   firebase.json já publica esta pasta e as regras do Firestore)
4. O console mostra o link https://iroxfox-f3b91.web.app — use esse
   link para instalar o app no celular.
5. Para publicar só as regras depois de uma alteração:
   firebase deploy --only firestore:rules

ONDE FICAM OS DADOS
- localStorage, chave "treinos.v1", no próprio aparelho. A chave
  interna continua com esse nome para não perder os dados já salvos.
- Se você entrar com uma conta, uma cópia é guardada no Firestore em
  users/{seu-uid}, acessível apenas por você (veja firestore.rules).
- Sem conta, nenhum dado é enviado para fora.
- Limpar os dados do site no Chrome apaga os treinos do aparelho; se
  estiver logado, eles voltam ao entrar de novo.
- Cada dia guarda um objeto de treino. Exemplo:
  {
    groups: ["perna", "abdomen"],
    exercises: {
      perna: [
        {
          name: "panturrilha",
          sets: [
            { reps: 10, weightKg: 5 },
            { reps: 21, weightKg: 8 }
          ]
        }
      ],
      abdomen: [{ name: "prancha", sets: [{ reps: null, weightKg: null }] }]
    },
    weightKg: 60
  }
- "weightKg" no topo é o peso corporal do dia.
- Cada série guarda "reps" (repetições) e "weightKg" (peso da série).
- Registros antigos de um só grupo usam { group: "perna" } e continuam
  sendo lidos (workoutGroups); o weightKg antigo é tratado como o peso
  do dia.
- Exercícios no formato antigo ({ name, sets: 3, weightKg: 40 }) também
  continuam sendo lidos (exerciseSets): viram 3 séries com o mesmo peso.
- Status explícito usa { status: "descanso" } ou { status: "pendente" }.

VERSÃO E CACHE
- A versão aparece no topo do app: "IRONFOX · V5.7.2".
- Toda alteração no app deve gerar uma versão nova. Isso muda a URL
  do CSS e do JS e o nome do cache, garantindo que o Chrome baixe a
  versão atualizada em vez de reaproveitar a antiga.
- Para subir a versão (patch):
  node scripts/bump-version.mjs
- Também é possível forçar:
  node scripts/bump-version.mjs minor
  node scripts/bump-version.mjs major
  node scripts/bump-version.mjs 5.1.2
- O script atualiza a versão em: version.json, src/config.js,
  index.html, sw.js e na linha "Versão atual" deste arquivo.
- Todos os imports internos de JavaScript também recebem a versão
  automaticamente, para o navegador nunca misturar arquivos antigos
  com novos (isso evita tela preta depois de uma atualização).

SE A TELA FICAR PRETA
- Recarregue a página: o app mostra uma mensagem de erro quando algo
  não carrega.
- Em último caso, limpe os dados do site no Chrome (Configurações do
  site > localhost > Limpar e redefinir) e abra de novo.

PRÓXIMAS TELAS
- A navegação já suporta novas telas: crie o módulo em src/screens/
  e registre-o em src/screens/index.js. A barra de navegação aparece
  automaticamente quando houver mais de uma tela visível.
- Próximos passos prováveis: exportar os treinos, metas por grupo e
  lembretes.
